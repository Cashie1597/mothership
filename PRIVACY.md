# Privacy

Mothership runs in your browser. It has no account, server-side profile, database,
analytics, advertising, or telemetry. The app does not make requests to external
services.

Your selected mission categories, setup-complete flag, data version, and up to
five recent mission IDs are saved in your browser's `localStorage` under
`mothership.profile.v1`. Energy and time choices are kept only for the current
page session. The app does not use cookies.
You can remove the saved data with **Reset local setup** or by clearing site data
in your browser.

Browser storage belongs to a specific site origin and browser profile. It does
not sync across devices. Private browsing and browser settings may prevent data
from persisting. If storage is unavailable, the app still runs, but setup will
not be remembered after a reload.

Opening the hosted site necessarily requests its static files from GitHub Pages.
GitHub may process those requests under its own policies. No profile data is
included in requests made by this app.
